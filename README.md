# Ranjitha Yellur · EPK

Electronic press kit for Ranjitha Yellur, singer, live performer and playback singer.

- `index.html` is the whole page. Open it through any static server.
- `Ranjitha-Yellur-EPK.pdf` is the print version, generated from the same page.
- `media/` holds the stage videos, their posters and the stage photos. `photos/` holds the hero stage photo (`ranjitha-stage.webp`) and the earlier portraits.
- `gradient-ascii.js` is the testimonial background, ported from React Bits' GradientASCII.

## Before publishing

- Draft notes are hidden by default. Set `data-draft="true"` on the `<html>` tag to show them while editing.
- The live clips use Instagram embeds, which set cookies, so the hosted page needs a cookie notice.
- Re-check the Instagram follower count.
